# 전역 상태 라이브러리 미도입

- 상태: accepted
- 기록일: 2026-10-15

## 맥락

현재 조직, 로그인 사용자, 필터 같은 값이 전역 상태 후보로 보일 수 있습니다.

## 결정

전역 상태 라이브러리를 도입하지 않습니다. 서버 데이터는 TanStack Query 캐시, 화면 간 공유 값은 URL과 props를 우선합니다.

## 근거

- 전역 상태 후보 대부분이 서버 상태, URL, 폼 상태로 해결됩니다.
- 의존성과 상태 동기화 지점을 줄입니다.

## 고려한 대안

- Zustand 등 도입: 실제 필요가 확인되기 전에는 서버 데이터 복제 위험만 늘어납니다.

## 영향 범위

- 상태 관리 방식 전반

## 검증 또는 재검토 조건

- 서로 떨어진 화면이 URL·서버에 둘 수 없는 상태를 함께 바꿔야 하면 Zustand 등을 검토합니다.
