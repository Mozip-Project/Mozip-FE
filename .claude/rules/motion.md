# 모션과 스크롤

## 모션 목적

- 모션은 `.claude/references/product-brief.md`의 제품 메시지 또는 Figma에 명시된 의도를 설명하는 역할만 수행합니다.
- Figma, 제품 메시지, 사용자 상호작용 중 하나로 설명할 수 없는 모션은 추가하지 않습니다.
- 모션 전과 후 모두에서 콘텐츠 순서, CTA 위치, 읽기 흐름이 유지되어야 합니다.

## 구현 기준

- `prefers-reduced-motion` 사용자의 자동 재생·강한 이동·패럴랙스를 줄이거나 제거합니다.
- 스크롤 위치에 따라 레이아웃 측정을 반복하거나 대형 이미지를 매 프레임 다시 그리지 않습니다.
- 가능한 `transform`과 `opacity`를 우선하고, width, height, top, left처럼 레이아웃을 반복 계산하는 속성의 지속 애니메이션은 피합니다.
- CSS 전환만으로 충분한 효과에 JavaScript animation loop를 추가하지 않습니다.
- 드래그·스크롤 상호작용은 마우스와 터치 모두에서 사용할 수 있어야 합니다.
- observer, listener, animation frame은 섹션이 사라질 때 정리하고, 동일한 전역 listener를 여러 섹션에서 중복 등록하지 않습니다.

## 사용자 제어와 검증

- 애니메이션이 실패해도 콘텐츠·내비게이션·CTA를 이용할 수 있어야 합니다.
- 시간 기반 모션의 duration·delay는 의미와 단위를 가진 상수로 두고, 여러 요소의 서로 다른 값이 우연히 맞물리지 않게 합니다.
- 자동 재생은 사용자의 읽기를 가리지 않아야 하며, 움직임 자체가 유일한 정보 전달 수단이 되어서는 안 됩니다.
- 스크롤 모션을 추가하거나 수정하면 reduced motion, 키보드 탐색, 작은 화면에서의 읽기 흐름을 함께 확인합니다.
