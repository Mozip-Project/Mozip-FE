# 서버 상태는 TanStack Query로 관리

- 상태: accepted
- 기록일: 2026-10-15

## 맥락

MOZIP 화면 대부분은 로그인 후 서버 데이터를 읽고 쓰는 화면입니다. 예를 들어 평가를 저장하면 지원자 목록과 현황이 함께 바뀌어야 합니다.

## 결정

브라우저에서 서버 데이터를 읽고 쓰는 화면은 TanStack Query를 사용합니다. 공개 조회 화면은 Server Component에서 가져오는 것을 우선합니다.

## 근거

- 캐시 무효화, 재시도, 로딩·에러 상태를 직접 구현하지 않아도 됩니다.
- 폴링(`refetchInterval`)을 같은 도구로 처리합니다.

## 고려한 대안

- Server Component와 Server Actions만 사용: 백엔드가 따로 있어 Next 서버가 중간 프록시가 되고, 상호작용이 많은 운영진 화면에 맞지 않습니다.
- 직접 구현한 fetch + state: 캐시 동기화 버그 위험이 큽니다.

## 영향 범위

- 서버 데이터를 쓰는 모든 Client Component
- `.claude/rules/data-fetching.md`

## 검증 또는 재검토 조건

- 공개 조회와 로그인 후 화면의 데이터 조회 방식이 섞이지 않는지 확인합니다.
