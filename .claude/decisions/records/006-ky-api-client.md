# HTTP 클라이언트는 ky

- 상태: accepted
- 기록일: 2026-10-15

## 맥락

API 호출은 공용 API 클라이언트 한 곳을 거치는 것으로 확정되어 있습니다(`docs/ARCHITECTURE.md` 확정 3번).

## 결정

공용 API 클라이언트는 ky 인스턴스 하나로 만듭니다.

## 근거

- fetch 기반이라 서버와 브라우저 모두에서 동작합니다.
- 재시도, 타임아웃, 요청·응답 훅을 기본으로 제공해 인증 만료 처리 같은 공통 로직을 한 곳에 둘 수 있습니다.

## 고려한 대안

- axios: Next.js의 fetch 확장을 거치지 않고 번들이 큽니다.
- 직접 만든 fetch 래퍼: 의존성은 없지만 재시도·훅을 직접 구현해야 합니다.

## 영향 범위

- 공용 API 클라이언트와 도메인 API 함수

## 검증 또는 재검토 조건

- 공용 클라이언트 한 곳에서만 사용하므로 교체가 필요하면 그 파일만 바꿉니다.
