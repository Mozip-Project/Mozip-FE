# 폼과 검증은 react-hook-form + zod

- 상태: accepted
- 기록일: 2026-10-15

## 맥락

지원서 작성, 문항 설정, 프로필처럼 입력 항목과 검증 규칙이 많은 폼이 핵심 화면입니다.

## 결정

폼 상태는 react-hook-form, 검증 스키마는 zod로 작성합니다.

## 근거

- 문항 추가·삭제 같은 동적 필드를 지원합니다.
- 긴 폼에서 입력마다 전체 화면이 다시 렌더링되지 않습니다.
- zod 스키마를 폼 검증과 API 응답 검증에 함께 쓸 수 있습니다.

## 고려한 대안

- React 기본 state와 직접 검증: 동적 폼과 검증 규칙이 늘어날수록 유지 비용이 큽니다.

## 영향 범위

- 입력과 검증이 있는 모든 폼

## 검증 또는 재검토 조건

- 지원서 문항처럼 동적으로 만든 폼의 검증 방식이 운영진 문항 설정과 어긋나지 않는지 확인합니다.
